# 骨架驱动高斯泼溅数字人模块设计方案

## 概述

新建 `skinned_gaussian/` 模块，实现 SMPL 骨架驱动的 3D 高斯泼溅数字人。核心思路（参考 GauHuman）：
1. 高斯在 **canonical（rest pose）空间** 定义
2. 每个高斯存储 **蒙皮权重**（继承自最近 SMPL 顶点，可优化）
3. 给定新 pose，通过 **LBS (Linear Blend Skinning)** 将高斯从 canonical 变形到 posed 空间
4. 用 gsplat 渲染变形后的高斯

## 技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 骨架模型 | SMPL (24关节) | 最成熟、轻量，rtg132 环境可安装 `smplx` |
| 高斯绑定 | 自由高斯 + LBS 权重 | 最经典方法（GauHuman），实现简单 |
| 输入数据 | 静态高斯 PLY + SMPL 参数 | 先绑定后驱动，支持动画 |
| 权重初始化 | 最近 SMPL 顶点继承 | 稳定可靠，无需额外训练 |

## LBS 变形公式（核心数学）

给定 N 个高斯在 canonical 空间的属性（means^c, scales^c, quats^c）和蒙皮权重 w (N, K=24)：

### Mean（位置）变形
```
G_blend = Σ_k w_k * G_k   (3×4, 混合的仿射变换)
μ^posed = G_blend @ [μ^c; 1]   (齐次坐标)
```

### 协方差变形（旋转+缩放一起处理）
```
Σ^c = R^c @ diag(s^c) @ diag(s^c)^T @ (R^c)^T   (canonical 协方差)
Σ^posed = G_blend[:3,:3] @ Σ^c @ G_blend[:3,:3]^T
```
然后从 Σ^posed 分解出新的 rotation quaternion 和 scale（通过极分解或 SVD）。

### 简化方案（推荐先用）
GaussianAvatars 的简化：固定 rotation = identity，只用 LBS 移动 means，scale 用标量。这样 LBS 只需处理位置，避免了协方差分解的复杂性。

**本方案采用混合策略**：
- Means: 完整 LBS 仿射变换
- Rotation: 用 G_blend 的旋转部分（极分解 R̃）旋转 canonical quaternion
- Scale: 用 G_blend 的缩放部分（极分解 S̃）缩放 canonical scale

### 2. `skinning.py` — LBS 变形核心

```python
def lbs_deform_gaussians(means_c, scales_c, quats_c, weights, joint_transforms):
    """将 canonical 高斯通过 LBS 变形到 posed 空间。
    
    Args:
        means_c: (N, 3) canonical 空间高斯中心
        scales_c: (N, 3) canonical 空间高斯尺度（activated）
        quats_c: (N, 4) canonical 空间高斯四元数
        weights: (N, K) 蒙皮权重，K=24
        joint_transforms: (K, 4, 4) 每关节变换矩阵
    
    Returns:
        means_p: (N, 3) posed 空间高斯中心
        scales_p: (N, 3) posed 空间高斯尺度
        quats_p: (N, 4) posed 空间高斯四元数
    """
    # 1. 混合变换: G_blend = Σ_k w_k * G_k → (N, 3, 4)
    #    G_blend[:, :, :3] = 旋转+缩放部分, G_blend[:, :, 3] = 平移部分
    
    # 2. Mean 变形: μ^p = G_blend[:3,:3] @ μ^c + G_blend[:3,3]
    
    # 3. 极分解: G_blend[:3,:3] = R̃ @ S̃ (polar decomposition)
    #    R̃: 旋转矩阵 → 转 quaternion
    #    S̃: 缩放矩阵 → 取对角线作为 scale
    
    # 4. Rotation 变形: q^p = q_R̃ ⊗ q^c (四元数复合)
    
    # 5. Scale 变形: s^p = S̃_diag * s^c
```

### 3. `skinned_gaussians.py` — 蒙皮高斯类

    # 参数（全部在 canonical 空间）：
    _means: (N, 3)       # canonical 位置

    _quats: (N, 4)       # 原始四元数
    _opacities: (N,)     # logit
    _sh0: (N, 1, 3)      # SH DC

## 关键技术要点

### 极分解（Polar Decomposition）
LBS 混合后的矩阵 G_blend = Σ w_k * G_k 不是正交矩阵。需要极分解 G = R̃ * S̃ 来分离旋转和缩放：
- R̃ 通过 QR 分解或迭代极分解获取
- S̃ = R̃^T @ G（对称正定矩阵，对角线为 scale）

### 蒙皮权重归一化
权重通过 softmax 归一化：`w = softmax(raw_weights)`，确保 Σ w_k = 1。

### 可微性
整个 LBS 变形是可微的——可以端到端优化蒙皮权重和 canonical 高斯属性。但 MVP 阶段先用固定权重（从 SMPL 继承），不做联合优化。
