# 多视角高斯优化模块设计方案

## 概述

在 TripoSplat 仓库中新建一个独立模块 `multiview_refine/`，实现「单图初始化高斯 → 坐标系/尺度对齐 → gsplat 可微渲染多视角优化」的完整流程。模块以独立 CLI 脚本 `run_refine.py` 驱动，不修改 `triposplat.py` 核心代码。

## 文件结构

```
E:\Code\TripoSplat\multiview_refine\
├── __init__.py
├── cameras.py          # Nerfstudio transforms.json 解析 → OpenCV 相机
├── gsplat_wrapper.py   # gsplat 0.1.0 两步式渲染封装（project + rasterize）
├── gaussian_model.py   # 可优化高斯参数类（nn.Parameter，torch.optim.Adam，densification）
├── losses.py           # L1 + DSSIM 损失（torchmetrics SSIM）
├── alignment.py        # 深度+轮廓 ICP 对齐，估计 7-DoF 相似变换
├── refine.py           # 核心编排：初始化→对齐→优化循环→导出
└── vis_utils.py        # 渲染对比图/点云可视化（用于调试）
run_refine.py           # 顶层 CLI 入口
```

## 各模块设计

### 1. `cameras.py` — 相机 I/O 与坐标系转换

**输入**：Nerfstudio `transforms_{train,val,test}.json`（参考 `static/000001/mvs/`）
**输出**：`Camera` dataclass 列表，含 OpenCV 约定的 w2c、内参

```python
@dataclass
class Camera:
    w2c: torch.Tensor        # (4,4) world→camera, OpenCV 约定 (+Y down, +Z forward)
    c2w: torch.Tensor        # (4,4) camera→world
    position: torch.Tensor   # (3,) 相机中心（世界坐标）
    fx: float; fy: float
    cx: float; cy: float
    width: int; height: int
    image: torch.Tensor      # (3,H,W) float32 [0,1]
    alpha: torch.Tensor | None  # (1,H,W) 前景 mask（可选）
    cam_idx: int
    file_path: str
```

**关键转换**（transforms.json 的 `transform_matrix` 是 OpenGL c2w）：
- `c2w_opencv = c2w_opengl @ diag(1, -1, -1, 1)` — 翻转 Y、Z 轴
- `w2c = inverse(c2w_opencv)`
- 每帧内参从 JSON 的 `fl_x/fl_y/cx/cy/h/w` 直接读取（变焦距，不能只用全局值）

**图像加载**：`file_path` 无扩展名 → 追加 `.png`；用 PIL 加载 → 转 float32 → 归一化到 [0,1] → (3,H,W) tensor。可选降采样（`--image_scale`，默认 1.0，实际训练时降到 0.5 以节省显存）。

### 2. `gsplat_wrapper.py` — gsplat 0.1.0 渲染封装

gsplat 0.1.0 是两步式 API（`ProjectGaussians.apply` + `RasterizeGaussians.apply`），非后来的单函数式。封装为一个函数：

```python
def render(means, scales, quats, colors, opacities, camera: Camera,
           sh_degree: int = 0, background=None) -> torch.Tensor:
    """返回渲染图 (3,H,W)。means(3D), scales(raw log), quats(raw), 
       colors(SH coeffs (N,1,3) for degree 0), opacities(activated 0-1)。
    """
    # 1. 构造 viewmat(w2c), projmat(投影矩阵 4x4)
    viewmat = camera.w2c  # (4,4)
    projmat = get_projmat(camera)  # 透视投影矩阵，含 fx/fy/cx/cy/near/far
    # 2. 投影：ProjectGaussians.apply(means3d, scales, glob_scale=1.0, quats, 
    #         viewmat, projmat, fx, fy, cx, cy, H, W, tile_bounds, clip_thresh=0.01)
    #   → (xys, depths, radii, conics, num_tiles_hit, cov3d)
    # 3. SH→颜色（degree 0 时直接用 DC 系数，跳过 SphericalHarmonics）
    # 4. 光栅化：RasterizeGaussians.apply(xys, depths, radii, conics, 
    #         num_tiles_hit, colors, opacity, H, W, background)
    #   → out_img (3,H,W)
```

**projmat 构造**：标准透视投影矩阵 NDC，结合 viewmat 得到 `projmat = projmat_ndc @ viewmat`（gsplat 0.1.0 的 ProjectGaussians 同时乘了 viewmat 和 projmat，需要传入组合后的 4×4 矩阵；参考 `gsplat._torch_impl.project_pix`/`ndc2pix` 的约定确认传入 `projmat` 是否已含 viewmat）。**实现时需先测试验证**：用已知相机+已知高斯渲染，对比预期投影位置，确认 projmat 的正确组合方式（这是 gsplat 0.1.0 最易出错的地方）。

### 3. `gaussian_model.py` — 可优化高斯模型

参考 faster-gs 的 `Gaussians` 类设计（但去除 NeRFICG 依赖，用标准 `torch.optim.Adam`）：

```python
class RefineableGaussians(torch.nn.Module):
    # 参数（全部 nn.Parameter，存储 raw/pre-activation 值）：
    _means: (N, 3)              # 世界坐标（对齐后）
    _scales: (N, 3)             # log 空间
    _quats: (N, 4)              # 未归一化四元数 (w,x,y,z)
    _opacities: (N, 1)          # logit 空间
    _sh_dc: (N, 1, 3)           # SH degree 0（DC 系数）
    # SH degree 0，不升级（用户已确认）

    # 从 TripoSplat Gaussian 对象初始化：
    @classmethod
    def from_tripo_splat(cls, gs, similarity_transform) -> 'RefineableGaussians':
        """从 TripoSplat 的 Gaussian 对象 + 7-DoF 相似变换创建。
        - means: gs.get_xyz @ R.T * s + t  （先变换到 OpenCV 世界坐标）
        - scales: log(gs.get_scaling)  （已是激活后的 scale，取 log 回到 raw）
        - quats: gs._rotation + gs.rots_bias  （raw 四元数，需用 R 旋转）
        - opacities: logit(gs.get_opacity)  （从激活值回到 logit）
        - sh_dc: gs._features_dc  （直接复制，形状 (N,1,3)）
        """

    # 激活属性（property）：
    @property means → _means
    @property scales → _scales.exp()
    @property quats → F.normalize(_quats)
    @property opacities → _opacities.sigmoid()
    @property colors → _sh_dc  # degree 0，DC 直接作为颜色（配合 SH C0 系数）

    # 优化器设置：
    def training_setup(self, cameras_extent):
        # 6 个参数组，不同学习率（参考 faster-gs cfg_args）：
        # means: 1.6e-4 * extent（带 LR 衰减调度）
        # sh_dc: 2.5e-3
        # opacities: 5e-2
        # scales: 5e-3
        # quats: 1e-3
        self.optimizer = torch.optim.Adam(param_groups, eps=1e-15)

    # Densification（完整 clone/split/prune，参考 faster-gs Model.py:311-365）：
    def densify_and_prune(self, grad_threshold, min_opacity, extent, prune_large):
        # 用屏幕空间梯度（需从 gsplat backward 获取，见下文）
        # clone: 小高斯 + 高梯度 → 复制
        # split: 大高斯 + 高梯度 → 分裂为2，scale×0.625，位置偏移采样自自身协方差
        # prune: 低透明度 / 退化四元数 / 过大尺度
        # 重建 Adam optimizer state（标准 Adam 需手动处理新增参数的 state）

    def reset_opacities(self): # 每 3000 步，clamp 到 logit(0.01)
    def save_ply(self, path):  # 标准 3DGS PLY 格式（含 normals 占位）
```

**densification 梯度来源**：gsplat 0.1.0 不像 faster-gs 那样内置 `densification_info` 缓冲区。替代方案：每个 densification interval 期间，记录 `means` 参数的梯度幅值（`_means.grad.abs().mean(dim=-1)`），用移动平均累积，作为 densification 判据。这是 3DGS 原始论文的方法（screen-space position gradient），在 gsplat 中可通过 `means.grad` 间接获取（因为投影含 means 的贡献，梯度会回传到 means）。

### 4. `alignment.py` — 深度+轮廓 ICP 对齐

估计 7-DoF 相似变换 `s, R(3×3), t(3)` 将 TripoSplat 高斯从归一化 AABB `[-0.5,0.5]` 变换到真实相机 OpenCV 世界坐标系：

```python
def estimate_similarity_transform(init_gaussians, init_camera, init_image, depth_estimator):
    """返回 (scale, R, t) 使 init_gaussians 变换后与真实场景对齐。
    
    步骤：
    1. 用 gsplat 渲染初始化高斯在 init_camera 视角下的深度图 D_render
    2. 用 Depth Anything V2（pipe.depth_estimator）估计真实 init_image 的深度 D_real
    3. 将两幅深度图反投影到 3D 点云：
       - 用 init_camera 内参将每个像素反投影
       - D_render → P_render (渲染点云，在 TripoSplat 坐标系)
       - D_real → P_real (真实点云，在 OpenCV 世界坐标系)
    4. 轮廓约束：只保留前景区域的点（D_real 用 BiRefNet 的 mask；D_render 用渲染 alpha>阈值）
    5. ICP 配准（scipy/Open3D 或自实现）：
       - 初始化：将 P_render 质心对齐到 P_real 质心，尺度 = std(P_real)/std(P_render)
       - 迭代：最近点匹配 → 估计 s,R,t → 变换 → 重复 N 次
       - 用 Umeyama 方法（scipy.spatial.Procrustes 或 sklearn）求闭式解
    6. 返回 (scale, R, t)
    """
```

**用到的现有代码**：
- `TripoSplatPipeline.depth_estimator`（`triposplat.py:632`，Depth Anything V2 Small）
- BiRefNet 前景 mask（`pipe.preprocess_image` 已用，也可单独调 `rmbg.remove_background`）

**数值稳定**：深度图反投影前先归一化到 [0,1]；点云下采样到 ~5000 点做 ICP；Umeyama 闭式解作为初始值 + 少量 ICP 迭代精化。

### 5. `losses.py` — 损失函数

```python
def compute_loss(rendered, gt, lambda_dssim=0.2):
    """0.8*L1 + 0.2*DSSIM（与 3DGS/faster-gs 默认一致）"""
    l1 = F.l1_loss(rendered, gt)
    dssim = 1 - ssim(rendered, gt)  # torchmetrics SSIM
    return 0.8 * l1 + 0.2 * dssim
```

用 `torchmetrics.functional.structural_similarity_index_measure`（已确认可用）。可选 LPIPS 正则（lpips 0.1.4 已装）。

### 6. `refine.py` — 核心编排

```python
def refine_from_multiview(
    pipe: TripoSplatPipeline,
    image_dir: str,
    transforms_json: str,
    init_view: str,            # e.g. "00.png"
    num_init_gaussians: int = 262144,
    num_iterations: int = 30000,
    image_scale: float = 0.5,
    output_dir: str = "refine_output",
    ...
) -> RefineableGaussians:
    
    # ── 阶段 1: 单图初始化 ──
    init_image_path = os.path.join(image_dir, init_view)
    tripo_gaussian, prepared = pipe.run(init_image_path, 
                                         num_gaussians=num_init_gaussians,
                                         remove_background=True)
    
    # ── 阶段 2: 加载全部相机 & 图像 ──
    cameras = load_cameras(transforms_json, image_dir, image_scale)
    init_camera = find_camera_by_filename(cameras, init_view)
    
    # ── 阶段 3: 坐标系/尺度对齐 ──
    init_image_full = load_image(init_image_path, image_scale)
    s, R, t = estimate_similarity_transform(tripo_gaussian, init_camera, 
                                             init_image_full, pipe.depth_estimator)
    
    # ── 阶段 4: 转换为可优化高斯 ──
    model = RefineableGaussians.from_tripo_splat(tripo_gaussian, (s, R, t))
    cameras_extent = compute_cameras_extent(cameras)  # max camera-center distance × 1.1
    model.training_setup(cameras_extent)
    
    # ── 阶段 5: 优化循环 ──
    train_cameras, test_cameras = split_train_test(cameras, init_view)
    grad_accum = torch.zeros(model.n_gaussians)  # 梯度累积器
    
    for iteration in range(1, num_iterations + 1):
        model.train()
        model.update_learning_rate(iteration)
        
        # 随机选一个训练视角
        cam = random.choice(train_cameras)
        rendered = render(model, cam, background=bg_color)
        gt = cam.image
        
        loss = compute_loss(rendered, gt)
        loss.backward()
        
        # 累积 means 梯度（用于 densification）
        if model._means.grad is not None:
            grad_accum += model._means.grad.detach().abs().mean(dim=-1)
        
        model.optimizer.step()
        model.optimizer.zero_grad()
        
        # Densification（iter 600~14900，每 100 步）
        if 600 <= iteration < 15000 and iteration % 100 == 0:
            model.densify_and_prune(grad_threshold=0.0002, min_opacity=0.005,
                                    extent=cameras_extent, prune_large=iteration>3000,
                                    grad_accum=grad_accum)
            grad_accum = torch.zeros(model.n_gaussians)
        
        # Opacity reset（每 3000 步）
        if iteration % 3000 == 0 and iteration < 15000:
            model.reset_opacities()
        
        # 日志 & 验证
        if iteration % 500 == 0:
            psnr = eval_psnr(model, test_cameras)
            log(f"iter {iteration}: loss={loss:.4f}, psnr={psnr:.2f}, n_gs={model.n_gaussians}")
            save_comparison_figure(model, test_cameras, output_dir, iteration)
    
    # ── 阶段 6: 导出 ──
    model.save_ply(os.path.join(output_dir, "refined.ply"))
    model.save_splat(os.path.join(output_dir, "refined.splat"))
    return model
```

## 关键技术决策与风险

### 已确认的决策（来自用户）
| 决策 | 选择 |
|---|---|
| 相机来源 | Nerfstudio transforms JSON |
| 对齐方法 | 深度+轮廓 ICP |
| 渲染库 | **gsplat 0.1.0**（已安装，纯 PyTorch） |
| 初始化视角 | CLI 单独参数 `--init_view` |
| 模块形态 | 独立模块 + CLI |
| Densification | 完整 clone/split/prune |
| SH degree | 保持 degree 0 |

### 坐标系转换链
```
TripoSplat 高斯 (AABB [-0.5,0.5], 模型坐标系)
    │  应用 7-DoF 相似变换 (s, R, t)  ← ICP 对齐估计
    ▼
OpenCV 世界坐标系 (+Y down, +Z forward)
    │  应用 camera.w2c
    ▼
相机坐标系 → projmat → NDC → 像素 → gsplat 渲染
```

transforms.json 的 `transform_matrix` 是 **OpenGL c2w**（+Y up, -Z forward），转 OpenCV：`c2w_cv = c2w_gl @ diag(1,-1,-1,1)`。

### gsplat 0.1.0 适配风险（需实现时验证）

1. **projmat 组合方式**：gsplat 0.1.0 的 `ProjectGaussians` 同时接受 `viewmat` 和 `projmat`，需确认 `projmat` 是纯投影矩阵还是 `projmat @ viewmat` 的组合。**验证方法**：先用 1 个高斯、1 个已知相机渲染，检查投影像素坐标是否正确。参考 `gsplat._torch_impl.project_pix` 和 `ndc2pix` 的实现来确认。

2. **梯度获取（densification）**：gsplat 0.1.0 不内置 densification_info 缓冲区。替代方案是用 `means.grad` 的累积幅值作为 densification 判据。这是可行的（3DGS 原始论文就用屏幕空间位置梯度），但需确认 gsplat 的 backward 确实将梯度传到 means。

3. **Adam optimizer state 与 densification**：faster-gs 用自定义 `FusedAdam` + `extend_param_groups` 处理增减参数。我们用标准 `torch.optim.Adam`，densification 后需要重建 optimizer（保存旧 state → 创建新 optimizer 加载旧 state），或者用更简单的方式：densification 时创建新 optimizer（接受 state 丢失的代价，因为 densification 本身就重置了相关参数的优化状态）。

### 可选增强（非 MVP）
- Mip-Splatting 3D filter（减少大高斯混叠）— 需额外 CUDA op，MVP 阶段跳过
- LPIPS 感知损失正则（lpips 已装）— 可作为 `--use_lpips` 开关
- 相机位姿联合优化（BA）— 用户已确认固定相机，MVP 不做
- 降采样策略：大图（2048×1500）需降采样到 1024×750 训练以省显存

## 实现顺序（建议分步）

1. **`cameras.py`** + 测试：加载 `transforms_train.json`，验证 c2w→w2c 转换，打印相机位置分布
2. **`gsplat_wrapper.py`** + 测试：用已知高斯渲染，验证 projmat 组合正确性（**最关键验证点**）
3. **`gaussian_model.py`**：从 TripoSplat Gaussian 转换 + 训练设置 + PLY 导出
4. **`losses.py`** + **`alignment.py`**：深度反投影 + Umeyama/ICP
5. **`refine.py`**：组装完整循环，先用固定高斯（不 densify）跑通，再加 densification
6. **`run_refine.py`** + 端到端测试：用 `static/000001/mvs/` 跑完整流程
