# 端到端验证：TripoSplat 单目高斯 → 多视角对齐 → 细节优化

## 流程

1. **TripoSplat 生成初始高斯**：从单张图像 `00.png` 生成 131K 高斯（在 model 坐标系中）
2. **坐标系映射**：
   - `R_model2cv = T_cv @ T_ply`（model→OpenCV，通过 PLY 中间步骤）
   - `R = init_cam.c2w[:3,:3] @ R_model2cv`（对齐到真实相机方向）
   - `scene_centre = median(相机位置)`（平移）
   - `scale`：通过轮廓 IoU 搜索最优缩放
3. **验证对齐**：在所有 32 个视角渲染对齐后的高斯，计算 PSNR
4. **多视角优化**：用 gsplat 可微渲染 + DefaultStrategy densification 优化 10000 迭代
5. **对比**：优化前 vs 优化后的 PSNR/SSIM + 渲染视频

## 执行命令

```bash
export PYTHONUTF8=1
python -c "
# 1. TripoSplat 生成高斯
# 2. c2w 对齐 + scale 搜索
# 3. 32 视角 PSNR 验证
# 4. 10000 迭代优化
# 5. 渲染对比视频
"
```

## 预期输出
- `alignment_test/aligned_init.ply` — 对齐后未优化的高斯
- `alignment_test/refined.ply` — 多视角优化后的高斯  
- `alignment_test/comparison.mp4` — 优化前后 vs GT 对比视频
- 逐视角 PSNR 表格
