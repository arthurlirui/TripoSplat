# 优化型骨架注册方案：YOLO-pose → 多视角重投影优化 → SMPL驱动高斯

## 核心改进

之前的方法用简单解析估计（骨骼长度比 + 角度计算），误差大（手腕 err=0.74）。参考 `mmforall/camsys/multiview_smpl_fitter.py` 的优化方法，改为**基于重投影误差的 Adam 优化**。

## 完整流程

### 1. 渲染高斯 → YOLO11-pose 检测 2D 关键点
- 从 32 个真实相机视角渲染高斯人体
- YOLO11-pose 检测每个渲染视角的 17 个 COCO 2D 关键点

### 2. 多视角 DLT 三角化 → 3D 关节初始值
- 用 DLT 三角化得到 3D 关节位置（世界坐标系）
- 用于初始化 SMPL 的 transl 和 global_orient

### 3. SMPL 优化拟合（核心改进）
用 Adam 优化器最小化**多视角重投影误差**：

```
Loss = Σ_view  ||project(SMPL_joints(θ), K, w2c) - yolo_2d||² / fx  (重投影)
     + λ_3d  ||SMPL_joints(θ) - triangulated_3d||²                    (3D关节)
     + λ_β   ||betas||²                                              (形状正则)
```

两阶段优化：
- **Stage 1**：只优化 `transl + global_orient`（快速全局对齐，50步）
- **Stage 2**：联合优化 `global_orient + body_pose + betas + transl`（150步）

关键技巧：2D 重投影误差除以焦距 fx，使其与 3D 误差（米）量纲一致。

### 4. 绑定高斯 + 渲染验证
- 用优化后的 SMPL 参数绑定高斯
- 渲染高斯 + 骨架叠加图像，与 GT 对比
