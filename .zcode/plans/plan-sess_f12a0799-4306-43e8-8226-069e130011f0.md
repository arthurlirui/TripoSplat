在 `E:/Code/TripoSplat` 仓库下添加一个 git 子模块：

1. 由于 `submodules/` 目录尚不存在，`git submodule add` 会自动创建它。
2. 执行：
   ```
   git submodule add https://github.com/arthurlirui/faster-gaussian-splatting.git submodules/faster-gaussian-splatting
   ```
   这会：
   - 把仓库克隆到 `submodules/faster-gaussian-splatting/`
   - 在仓库根目录生成 `.gitmodules` 文件（记录子模块 URL 与路径）
   - 在 git 索引中登记该子模块（一个特殊模式的 gitlink 条目）
3. 之后按需执行 `git submodule update --init --recursive` 初始化子模块内部嵌套子模块（如该仓库含有）。

注：当前处于 `main` 分支，按仓库规范在提交前应先开新分支；不过本任务仅要求"clone 作为子模块"，所以我只会执行 `git submodule add`，不会自动 commit。如需提交，请告诉我，我会先切到新分支再提交。
